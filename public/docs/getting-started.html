Welcome

Welcome to the MicStatusPro documentation. This guide will help you install, configure, and get the most out of MicStatusPro.

Getting Started Guide

Before you begin, make sure you have administrator rights on your computer and can install applications from the Microsoft Store.

Installation Steps

  1. Download MicStatusPro from the Microsoft Store.
  2. Launch the application after installation completes.
  3. Find your application in the system tray and drag down to the taskbar.

License Activation

Enter your 25-character product license key into the configuration utility during initial boot. If deploying in an offline environment, generate an activation request file and submit it via the customer dashboard.

Initial Standard Configuration

Default options are loaded when you first start

  • Mute/Unmute Sounds: Audio notifications are enabled by default so you can hear when your microphone status changes.
  • Mute/UnMute Border: Mute and UnMute sound is on to help audibly hear the mic status changed.
  • Border Thickness & Transparency The default settings are a thickness of 7 and transparency of 40%.
  • Colorblind Mode: Disabled by default. Enable this option for improved visibility. For best results, set the border thickness between 10 and 20.
  • Theme: By default, MicStatusPro follows your Windows theme. You can switch to Light or Dark mode at any time.
  • Start with Windows: Disabled by default. Enable this option if you want MicStatusPro to start automatically when you sign in to Windows

Quick-Start Workflow

After setup is complete, test MicStatusPro by muting and unmuting your microphone. Confirm that the visual indicators and sounds work as expected.

Premium Features

  • Premium Color Engine: Customize your mute and unmute colors using the built-in color picker.
  • Global Toggle: The default hotkey is Ctrl + Shift + M. You can change this shortcut, but be sure to test it as some key combinations may conflict with other applications.
  • Push to Talk: Turn any keyboard key into a push-to-talk button. By default, the Right Alt key is used. Hold the key to speak and release it to instantly mute your microphone.
  • Multi-Monitor Support: Display microphone status borders on your primary monitor or across all connected displays. MicStatusPro automatically adjusts when monitors are connected or disconnected.
  • Text Overlay: Display a draggable, transparent on-screen indicator that shows "Muted" or "Unmuted." You can customize the text and colors to match your preferences. By default, double-clicking the text overlay toggles your microphone between muted and unmuted.

System Requirements

Minimum specifications for deployment:

  • OS: Windows 10/11 (64-bit)
  • RAM: 200 MB available RAM
  • Storage: 200 MB available disk space
